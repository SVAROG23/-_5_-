## Описание задания

Написание программ на Python для построения графиков математических функций и визуализации данных из датасета Kaggle с использованием библиотек `matplotlib`, `numpy` и `pandas`.

## Структура проекта

В папке находятся следующие файлы:

1. `Графики_x_y.py` — скрипт для построения графиков функций \(y = x^2\) и \(y = x^3\).
2. `titanic/5.3.py` — скрипт для анализа и визуализации датасета "Titanic".
3. `titanic/train.csv` — исходные данные (датасет).

## Что делают программы:

1. **Графики_x_y.py** — запрашивает у пользователя диапазон и шаг (по умолчанию от -3 до 3 с шагом 0.5). Строит два графика на одном полотне: параболу (синий пунктир с кружочками) и кубическую параболу (красная сплошная линия с квадратиками). Добавляет сетку, легенду и подписи осей.
2. **titanic/5.3.py** — загружает данные с помощью `pandas`, выводит базовую статистику (первые строки, типы данных, пропуски) и строит 3 графика:
   * Общее количество выживших и погибших.
   * Распределение возраста пассажиров.
   * Выживаемость в зависимости от пола.

## Результат проверки

Все скрипты работают успешно. 
При запуске `Графики_x_y.py` открывается окно с графиком функций.
При запуске `titanic/5.3.py` в терминал выводится информация о датасете, а затем открываются три окна с графиками, наглядно демонстрирующие статистику пассажиров "Титаника".
